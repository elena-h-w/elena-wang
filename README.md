# Elena Wang – Personal Website

Live site: https://elenahw.com

## Overview

This is my personal website built with Next.js and Tailwind CSS.

The site highlights:
- My work in product marketing and GTM
- Hands-on AI experimentation (Waylena, Waylena Impact, Back on Track, and Lift & Stride)
- How I think about AI product mechanics and growth

No hero images, no animation, no special effects. The site is built like a document, so the work speaks for itself.

## Why This Site Matters

I believe marketing leaders in the AI era should understand product mechanics, model economics, and system design, not just positioning.

This site serves as a living portfolio of that work.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Vercel
- Google Analytics
